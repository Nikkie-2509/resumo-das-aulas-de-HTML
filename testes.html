Usando CSS

O CSS é nada mais do que o design do site, é nele que mudamos as cores, a posição, o tamanho, etc. Lembrando que, no CSS, para fazer essa modificação é
necessário fazer desta forma "(tag){aqui dentro você pode usar as diversas modificações}". Alguns exemplos podem ser citados, como:

  • background-color:(a cor que você quiser) --> Ele serve para mudar a cor de fundo;
  • color: (a cor que você quiser) --> Ele serve para mudar a cor de textos;
  • text-decoration: (outra caracteística) --> Ela serve para modificar a forma como os textos vão aparecer, incluindo atuar no hover;
  • border-(outra caracteística) --> Ela atua em tabelas e imagens, no caso, ela pode modificar a espessura das bordas, o quão
    arredondada será as bordas de algo ou tamém mudar a cor das bordas;
